## 3. 计算公平性与计时：实际发现及处置

### 3.1 M 的公平性成立，但含义必须写准确

所有方法每次调用均新建 TransitionCache；缓存按整数观测计数状态、路径、结果索引，不跨方法共享。缓存命中不计新后验计算。搜索展开一个动作的正概率分支前检查所需更新数；迭代加深预算耗尽时只返回最后完成的完整截断策略，未完成深度的计算仍计入消耗。

因此可以称为“**相同后继信念更新预算**”。`best_stop`、观测概率、完美信息上界、动作扫描和缓存命中仍需要计算，没有各计为一次 M。它们进入时间及相关计数。不能把该实验写成“相同总计算量/相同运行时间”。

### 3.2 旧 planning_seconds 的初始化范围偏宽

`runner.py:115–116` 在 `contexts()` 之前开始计时，而 `tasks.py:contexts` 总是先构造真实后验。correct 的规划本来需要该后验；reset 原本只需先验，却也承担为后续真实评价计算后验的耗时；misread 还会再计算错误解释的后验。

这是**计时语义问题，不是信息泄漏或效用计算错误**。固定 correct 条件的核心算法比较共用该输入过程，初始化没有给某个方法额外未来信息；跨记忆条件的纯规划速度比较不能由旧值支持。

决策：保留旧记录，明确其为实验入口的端到端观测耗时；报告主要用实际更新次数及正确模型下的效用—成本关系。不将 reset/misread 的耗时排名解释成算法优劣。若需要更精确的速度论断，再固定代表问题，在真实上下文构造之外进行独立计时；当前核心结论不依赖这类论断，无需为此重跑全部数据。

### 3.3 单进程不等于无争抢

`runner.py:174` 的 `timing_contended` 仅由 `workers > 1` 得出。它证明是否使用本项目的多个 worker，不观测其他工程或操作系统任务。`analysis.py` 中“uncontended”的措辞超出该字段证据；本机本轮也无法读取完整进程表。

报告应称“同一机器、单工作进程的观测耗时”，不称“隔离机器、无争抢性能”。CLI 在导入数值库前固定常用线程变量；正式 manifest 记录线程设置。最初懒导入开销也进入少数首个方法调用的时间。对通常非常短的任务，不据细小耗时差给出强速度结论。

### 3.4 检查点与别名

多预算轨迹保存的是不可变策略、标量统计和截至该点的累计耗时；多个 checkpoint 是同一任务的相关观测，不是独立样本。保存检查点本身的管理开销可进入后续点时间，故应称记录的累计端到端成本，不能包装为零开销的单预算微基准。

当前汇总已排除 alias 的独立计时，但 myopic/depth2 等方法的非alias计时可能只覆盖较难时域，不能与 exact 的全网格汇总直接形成同分布速度比较。报告需按同一设置/任务集合比较，或逐设置展示。别名只说明策略/价值的理论等价，不是额外一次实验胜利。

## 4. 理论和证书范围

T1–T5 的推导与当前研究模型一致：独立先验与已知能力、条件独立观测使能力分组计数充分；有限时域 Bellman 对所有首动作归纳；TV 界比较相同未来机制下的固定策略；免费类型信息与首测成本给出有效上界；返回策略达到下界，回传和安全剪枝保持区间有效。

重要区分：

- 正确历史对 reset 的**事前信息价值顺序**，与同一已实现历史下**真实最优策略不劣于固定 reset 策略**是两个论证。不能直接把不同信念的 V(b_H) 和 V(b_0) 逐历史排序。
- 数值上界使用 float64，验证容差用于验收，不是概率置信度；实数证明与舍入误差分别说明。
- 主实验 3240 次、压力组 120 次“证书通过”是同模型 exact 参照核验数量。大规模没有 exact 参照，其证书依据已验证回传算法和理论，不把“复算通过”说成“证明大规模下界已最优”。
- `upper-lower` 可以显著大于实际 regret；证书松不等于策略差，策略差也不由“有证书”免除。必须同时展示质量与宽度。

## 5. 统计口径与需要收窄的措辞

按设置等权、设置内任务配对 bootstrap 与固定网格设计相符。main 的各参数设置独立生成；large 的 n=0/3 共用先验，以 (K,B,index) 配对；stress 复用 main 子集，不增加独立任务数。34640 条结果是方法/变体/检查点记录，不是34640个独立样本。

95%区间是每项比较的近似 bootstrap 区间，不是所有图表结论联合95%正确的保证。探索性分层、多个成本/能力面板和多个预算应按效应大小描述，不以未校正的多项结果宣称“普遍显著”。固定样本中零差异产生 [0,0] 区间，不自动证明总体等效；只有模型结构给出等价关系时，才能用理论作一般性结论。

R=1 让净效用有统一量纲，但没有预先指定“实际有意义”的阈值。当前报告可以给具体绝对差异，不能将小的非零平均收益自动称为“明显实际提升”。压力测试样本只覆盖指定概率偏移和一次重采样，不足以支持对任意模型误设的稳健性。

## 6. 本轮研究循环与处置

- **实际证明：** 保存内容可追溯；代表性历史条件下固定策略评价与独立有理数枚举一致；预算更新计数与实际调用一致；没有发现阻断质量比较的策略执行错误。
- **替代解释：** 未计入后续在线规划、真实类型泄漏、评价器替换终止动作、遗漏重采样相关性，均有源码/定向独立证据排除。小收益与强基线仍需机制分析，不能由技术测试解释。
- **行动：** 继续复用旧质量数据；收窄计时措辞及统计推断范围；质量/成本/证书分开呈现。无需开展全量性能重跑或一般相关信念求解器。
- **报告影响：** Methods 明确定义 M、完整策略和真实条件评价；Results 将自然成本与等M比较分开；Discussion 说明初始界松、任务结构和统计范围；删去“无争抢计时”“普遍优于基线”等无证据表达。
- **未决项：** 实际剩余研究缺口是历史收益条件、连续测试频率与条件收益、搜索质量/证书机制。它们由专项分析处理，不能因本技术审阅通过就标记整个项目研究完成。

## 7. 搜索机制补充审阅

针对新增 `scripts/analyze_search.py`、`scripts/diagnose_tolerance.py` 和 `docs/report_v2.md` 的第6节，另完成如下检查。

### 7.1 深度完成门槛的公式

当前大规模 n=0 概率表为 (0,.5,.9)，先验三项均正。根处每条路径成功和失败均为正；第一层观测后，也仍保留可使重复测试成功/失败均可能的类型质量。根有2K条转移边，对应2K个不同的一次观测计数状态；每个状态的下一层再有2K条正概率边。转移缓存的键为 `(state,path,outcome)`，不同父状态的边即使落到同一个子状态也分别计算。因此深度1需2K次，完整深度2累计2K+(2K)²次。前一轮深度1的根边被缓存复用，不再重复计费。

`search/depth_completion.csv` 的两个预定任务与公式一致：K=20为40/1640，K=40为80/6480；保存策略与独立完成层策略一致。根处两分支正概率本身不足以保证此公式适用于任意概率表，例如确定性成功率可使下一层某分支变为零。报告应把条件写成“在当前 n=0 概率表下，根及第一层后的两种观测均为正概率”。该修正限制公式范围，不改变现有门槛解释。

### 7.2 199个容差干预任务

直接读取全部199条诊断记录和199棵保存策略，核对旧状态全部为 tolerance、新状态全部为 complete、新值达到原 exact 参照、界宽归零、更新数均不超过10000。没有只保留改善任务。选择诊断集合中 task_id 排序首个K=3任务 `002ad95faa97a4255bea`，按其真实历史重新建立有理数联合后验后，直接评价新冻结策略：

- 原搜索值 .8753846153846154；
- 独立新值 113861/130000 = .8758538461538462；
- 保存新值 .8758538461538463，误差 1.11×10⁻¹⁶。

完整复核摘要见 `technical/tolerance_review.json`。策略选择顺序不使用 epsilon；epsilon只决定在何时终止，因此保持任务、预算、模型和算法不变而仅取消正容差，是对这些已观察损失的直接机制干预。可以表述“这199个任务的原损失由正容差提前停止导致”；不能表述“搜索在任意规模只要取消容差就能在10000次内求到最优”。它是探索性机制诊断，不是新增独立确认样本，也不替换原主表。

### 7.3 上界对其他可执行策略的意义

同一规划模型下 U≥V*≥J(π_myopic)，所以 0≤V*−J(π_myopic)≤U−J(π_myopic)。这个推理不要求myopic出自搜索树，也不要求myopic的值低于原搜索下界。`certificate_tasks.csv` 保留了任务级上界、myopic值与两者计算次数，可以核查该上界。

但U来自运行搜索，myopic完整策略和值来自基线规划；如果把二者组合使用，至少按现有独立实现同时承担两个方法的工作。将它称为事后质量上界是正确的，将它归为myopic自身的免费保证不成立。报告第6.3节已明确额外搜索成本与未知真实regret，措辞可保留。

### 7.4 对报告的技术判断

`report_v2.md` 已区分滚动myopic与一次测试、有限测试时域与计算预算、主网格精确regret与大规模界、探索诊断与总体平均效果、自然成本与同M比较。取消正容差诊断回答了“小任务搜索为什么有损失”的替代解释；保留大规模未知最优值及证书成本，避免把该诊断外推为普遍优势。除7.1所列公式条件需明确外，本轮未发现新增计算结论与实现矛盾。
