# 模型、实验与证据协议

本文件定义当前研究口径；可执行参数见 [study.json](../configs/study.json)，正式输入以 [data](../data/README.md) 中的冻结清单为准。[原始提案](references/Proposal.md)与[课程要求](references/Project_Requirements.md)保留原文，用作来源材料。

## 模型与评价

类型顺序为 $(I,C,A)$。每条路径的潜在类型在任务中固定，主实验各路径先验独立。已知能力变化和相应成功概率表；给定类型与能力，各次测试及终止执行条件独立。测试只提供信息，每次支付成本 $\kappa$，最多测试 $B$ 次；最终执行一次，成功奖励为 $R$，并有已知成功率 $q_0$ 的 fallback。历史测试成本不进入新阶段效用。

规划与真实评价使用两套输入：规划信念决定策略，真实条件信念依据实际历史计算。correct 按历史发生时的能力解释历史；reset 恢复先验；misread 用当前能力解释历史。三种策略均在同一实际历史下的真实模型中评价。隐藏类型只用于历史生成，不提供给规划器；评价器不能重选保存策略的终止路径。

零概率观测分支保存最后有效规划信念下的停止动作。规划历史完全不可能时返回标记为 `incompatible_history` 的 fallback 策略，不生成虚假模型证书。平局优先停止，终止路径平局优先 fallback，其次按路径索引。

## 方法与计算计量

| 方法 | 行为 |
|---|---|
| STOP | 立即按规划信念选定终止路径 |
| Exact DP | 缓存整数新观测计数状态的有限时域 Bellman 递推 |
| Myopic | 每个决策点做一步前瞻，后续继续滚动决策 |
| Depth-2 / Depth-3 | 前瞻叶值为立即停止价值，执行时继续滚动重规划 |
| Blinkered | 分别求解只能继续测试单条路径的子问题，每个观测后重新比较路径 |
| Iterative deepening | 完成深度逐层增加的截断完整策略，返回最后完成层 |
| Bounded search | 使用可执行下界与成本修正 PI 上界展开部分树，回传并安全剪枝 |

所有方法返回完整、不可变的策略树。滚动策略构造全部可能分支的工作计入规划，评价阶段不再搜索。$B$ 是交互测试预算，$M$ 是后继信念实际计算次数：一个正概率分支的一次后验计算记一次，缓存命中不新增计数，方法之间不共享缓存。搜索按测试动作的结果分支原子展开；迭代加深未完成层的计算照计，但不返回半成品策略。

$M$ 不等于总 CPU 运算量。上界、动作扫描、缓存管理与回传进入耗时和相应计数。`planning_seconds` 包含上下文初始化，单 worker 不代表独占硬件；耗时只作同机器观测，不支持跨记忆纯算法或隔离机器速度排名。

等价结果保留标签和来源，不重复计算：$B=1$ 的 myopic、足够深的前瞻及 $K=1$ 的 blinkered 分别与 exact 等价；主网格 depth-3 覆盖完整测试时域。

## 正式实验

共同参数：$R=1,q_0=.5,p_I=0,p_A=.9,p_C(s_0)=.1$。每条路径独立等概率抽取三种先验：$(.2,.6,.2)$、$(.6,.3,.1)$、$(.1,.2,.7)$。

| 实验 | 参数与任务数 | 比较口径 |
|---|---|---|
| main | $K\in\{3,6,10\}, B\in\{1,2,3\}, n\in\{0,3\}, p_C(s_1)\in\{.1,.5,.9\}, \kappa\in\{.005,.02,.1\}$；162设置各20任务，共3240 | 记忆比较用 exact；规划比较固定 correct；搜索 $M=10000,\epsilon=.01$，迭代加深同 $M$ |
| large | $K\in\{20,40\},B\in\{4,6\},n\in\{0,3\},p_C(s_1)=.5,\kappa=.02$；8设置各20任务，共160 | 搜索 $M\in\{100,1000,10000\},\epsilon\in\{.01,.05\}$；迭代加深同 $M$；自然成本 STOP/myopic/blinkered |
| stress | 复用 main 中 $K=10,B=3,n\in\{0,3\},p_C(s_1)=.5,\kappa=.02$ 的40任务 | 未来概率表误设；转换时恰好一路径重采样 |

large 的 $n=0/3$ 在相同 $(K,B,任务编号)$ 下共享先验抽样。压力 A 保持历史模型正确，真实当前 $p_C=.5$，规划分别假定 $.4/.6$；与正确模型 exact 比较真实 regret。压力 B 均匀选择一条路径按原先验重采样，随后类型固定；真实分布是十个条件因子模型的混合。该组只比较固定策略，不使用未知真实最优值计算 regret。$n=0$ 重采样不改变事前分布。

正式种子为 `20261123`，开发种子为 `20261108`，bootstrap 种子为 `20261129`。任务和作业 ID 稳定，不依赖 Python 随机化 hash 或进程完成次序。方法别名、压力变体和预算检查点不是新的独立样本。

## 机制诊断与统计

机制分析复用全部正式任务。历史分析逐任务分解终止奖励差和测试成本差；序贯分析分解获益频率与条件收益；搜索分析分别报告质量、更新成本和证书宽度。

两个额外诊断有固定协议：序贯解析例子使用11个列明成本点；容差干预覆盖主实验全部199个搜索未达精确值的任务，仅将 $\epsilon=.01$ 改为0，保持 $M=10000$。它们是解析数值检查和已有任务上的探索性干预，不作为新增随机确认样本，也不替换原排名。

每个固定任务的净效用精确积分未知类型和未来结果，不加执行采样区间。跨任务比较使用设置等权、设置内任务配对的5000次 percentile bootstrap，给出逐比较95%区间。条件子群为探索性描述；预算检查点及复用任务保留相关关系。没有整份报告同时95%的保证，全零样本区间不证明总体等效。

浮点验收容差为 $10^{-10}\max(1,R+B\kappa)$；分析的 $10^{-10}$ 零分类不是最小有意义效应。未预设实用阈值时只报告绝对差异和区间。每组改变研究判断的分析，检查结论范围、效应、替代解释及是否需要针对性验证；不按显著性追加样本。结论与证据对应见[证据索引](evidence.md)。
