# 能力变化后如何重测失败路径：历史解释、序贯信息与有限计算

## 摘要

我们研究一个有限时域贝叶斯决策问题：路径的潜在类型固定，执行能力改变已知成功概率，历史测试和新测试共同影响最终路径选择。目标是最大化一次终止执行的期望奖励减去新测试成本。项目关注四个问题：历史应如何解释、连续测试何时值得、有限规划计算能提供怎样的策略与保证，以及有限样本概率估计如何影响真实决策。

理论上，按路径与能力分组的计数是充分统计量；只有初始信念误设时，策略损失可分解为类型分布误差和搜索误差；完美信息上界导出立即停止判据。完整主网格显示，有历史时正确解释相对重置的平均净效用提高0.08143，相对误读提高0.00639，但两种比较的机制明显不同。连续测试在解析例子中严格有价值，主网格中只有161/3240个任务的精确策略优于滚动myopic。大规模无历史组中，搜索在相同后继信念预算下平均优于迭代加深，却低于自然成本的myopic/blinkered。机制分析将这一现象联系到完整深度交付的计算门槛、浅层策略的充分性，以及找到好策略与证明策略好所需的不同工作。独立任务上的myopic根节点初始化缩小了证书，但额外搜索没有超过myopic效用，收益表现为认证信息而非更好的策略。新增单路径闭式区域说明重测发生在中间信念区间；24个较深机制任务中搜索均达到精确值，限定了大规模负面结论的范围；有限校准将估计DP的平均真实损失从m10的0.002068降至m300的0.000289。显式剪枝消融在20个既有大任务上保持策略与界不变，减少少量动作处理计数，却在本机匹配计时中略慢，进一步区分了计数节省与实际计算收益。结论针对已规定模型与任务分布，不声称验证了真实DPO训练。

本文件是统一研究入口：强化学习概念与代码的对应关系见[第2.5节](#rl-view)；历史与连续测试的原结果见第4–5节；搜索初始化的增量归因见第6.5节，显式剪枝的成本消融见第6.6节，重测及多路径决策机制见第5.1–5.3节，有限校准见第7.1节；文末的Proposal承诺表对应原计划与现有证据。完整证明在[理论说明](theory.md)，逐项判断及停止理由在[证据台账](evidence.md)，执行与复现命令见[使用说明](usage.md)。

## 1. 问题与研究定位

失败既可能表示路径永久不可行，也可能只是当时能力不足。如果能力提高后仍把旧失败当作当前能力下的失败，就可能错误排除有价值路径；但丢弃全部历史也会丢失识别优质路径的信息。我们把这个问题写为信念状态上的有限时域MDP，以便精确区分推断、决策和计算预算。

这里的测试只提供信息，奖励集中于终止选择。因此它属于有成本信息获取后的贝叶斯选择问题，与每次拉臂累计奖励的标准bandit目标不同。这个定位沿用 [Hay等，Selecting Computations: Theory and Applications](https://proceedings.mlr.press/r10/hay12a.html) 的问题框架。可执行策略作为下界、乐观价值作为上界的思想来自已有POMDP规划研究，例如 [Smith与Simmons，HSVI](https://longhorizon.org/trey/papers/smith04_hsvi.pdf)。我们的实现是面向本问题的有限树搜索，不把该规划思想作为新算法发明。

课程贡献在于：用明确的能力条件解释历史；将信息误读与有限搜索的误差放在同一分析中；通过精确评价和反例解释简单策略何时已经足够。DPO仅提供能力改变的应用动机；实验没有训练语言模型，也没有估计DPO的因果效果。

## 2. Method：模型、理论与算法

### 2.1 生成模型与真实评价

任务有K条路径，独立潜在类型Z_i∈{I,C,A}在任务中固定。I永久不可行，C的成功率随能力变化，A的成功率不变。已知各能力的概率表p_z(s)，未知路径类型；给定类型和能力，各测试及终止执行独立。fallback成功率为q₀。

历史按路径、能力记录成功/失败次数。旧历史成本是沉没成本。新阶段最多测试B次，每次付κ；STOP保存具体执行路径，最终只执行一次并获得成功奖励R。固定策略的净效用为

```math
J(\pi)=R P_\pi(\text{终止成功})-\kappa E_\pi N.
```

我们分开构造规划信念和真实条件信念。correct使用历史发生时的能力；reset使用先验；misread用当前能力解释旧历史。三种策略都在同一实际历史对应的真实模型中评价。评价器不能按真实后验重新选择终止路径。类型重采样压力组另按真实混合分布评价。

### 2.2 充分性、Bellman与信息价值

后验满足

```math
b_i(z)\propto b_i^0(z)\prod_s p_z(s)^{n^+_{i,s}}[1-p_z(s)]^{n^-_{i,s}}.
```

条件独立使历史似然只依赖这些计数；独立先验和已知观测机制使路径后验继续因子化。因此完整记录与正确分组计数定义相同决策问题。共享未知参数或未建模的选择性记录会破坏这些条件。

设μ_i(b)=Σ_z b_i(z)p_z(s₁)，S(b)=R max(q₀,μ₁,…,μ_K)。令τ表示给定测试路径和观测后的贝叶斯信念更新。剩余h次测试的最优值为

```math
V_0=S,\quad V_h(b)=\max\{S(b),\max_i[-\kappa+\sum_o P(o\mid b,i)V_{h-1}(\tau(b,i,o))]\}.
```

归纳证明：首动作是停止或某条路径测试，后续交给h−1时域最优策略。可忽略额外预算，因此V随B非减；每个固定策略的价值随成本非增，取最大后仍非增。测试次数本身不必单调。

完整历史可以模拟任意摘要策略，摘要也可以被忽略，因此**事前**最优信息价值有层级顺序。另一条不同论证是：对同一已实现历史，correct精确最优策略在该真实模型下不劣于reset等任何可执行策略。它不等于对不同信念直接比较V(b_H)与V(b₀)，也不保证有限搜索方法保留全部信息优势。

### 2.3 总误差与停止证据

若真实和假定的初始联合类型分布为P、Q，后续机制相同，对固定策略，给定类型后的期望回报范围为[−Bκ,R]。由全变差得到

```math
|J_P(\pi)-J_Q(\pi)|\le(R+B\kappa)\mathrm{TV}(P,Q).
```

将真实最优与假定模型搜索策略的损失拆为两次换分布和一次模型内规划误差，得到

```math
V_P^*-J_P(\pi_{Q,L})\le2(R+B\kappa)\mathrm{TV}(P,Q)+(U_Q-L_Q).
```

这里TV是联合分布距离。未来概率表也误设时，固定类型条件机制不同，不能直接使用此界。恰有一路径重采样会形成相关混合，不能把它替换为边缘乘积。该界用于解释误差来源，不宣称紧致。

免费获知全部类型的价值U_PI=R E[max(q₀,p_Z₁,…,p_ZK)]是上界。任意以测试开始的策略至少付一次成本，因此

```math
V_h(b)\le\max\{S(b),U_{PI}(b)-\kappa\},\quad h>0.
```

若U_PI−S≤κ，STOP已达到上界。独立后验下可用不同成功率的尾概率乘积在O(Km)时间计算U_PI，避免3^K枚举。完整证明、边界处理和概率重合情形见[理论说明](theory.md)。

### 2.4 方法与计算契约

精确DP缓存整数观测计数状态。myopic在每次决策处只看一步，但会在后续观测处继续重新决策；它不是“最多测一次”。depth-2/3使用滚动截断前瞻。blinkered每次分别求解只允许继续测单条路径的子问题，再选择首动作。所有滚动策略都提前构造成完整不可变树，构造全部分支的成本计入规划，评价阶段不搜索。

迭代加深逐层完成截断策略；预算耗尽时返回最后完成层，未完成层的消耗照计。上下界搜索初始下界为STOP，上界为成本修正PI；展开、回传和支配剪枝保留达到下界的完整策略。由归纳法有J(π_L)=L≤V*≤U。

计算预算M统计实际后继信念计算，一条正概率结果分支记一次，缓存命中不新增计数。缓存每方法独占。M不统计全部CPU运算，另报告扫描、耗时和策略构造成本。测试预算B与计算预算M严格区分。主比较不使用未知真实类型。

### 2.5 强化学习视角：状态、价值函数与策略求解

本项目研究部分可观测任务的信念状态MDP，采用已知模型下的有限时域规划。重点是选择信息获取动作、权衡即时成本与未来回报，不是通过反复训练提高执行能力。

| RL要素 | 本项目定义 | 代码对应 |
|---|---|---|
| 隐状态 | 固定但未知的联合路径类型Z；主模型先验独立 | `model.py`中的类型概率与信念 |
| 决策状态 | x=(b,h)：当前类型后验与剩余测试次数；模型参数在一次规划内固定 | `PlanningProblem`与规划递归的剩余时域 |
| 动作 | h>0时可测试路径i；任意h可停止并指定最终执行路径j，包括fallback | `policy.py`的`Test(i,...)`与`Stop(j)` |
| 观测与转移 | 测试产生成功/失败o，状态变为(τ(b,i,o),h−1)；路径类型不变 | `model.py`的预测概率和贝叶斯更新 |
| 奖励与回报 | 测试支付−κ，最终执行成功获R、失败获0；总回报R·1{成功}−κN | `ModelSpec`与`evaluation.py` |
| 策略 | π_h(b)决定测试哪条路径或执行哪条路径；策略树保存全部观测分支 | 各规划器返回的完整不可变Policy |
| 最优价值 | V_h(b)是从当前信念开始、最多再测h次的最优期望净回报 | `dynamic.py`的Bellman递归 |

这是有限回合、无折扣的目标（γ=1），最多B次测试后执行一次。执行后进入价值为0的终止状态；h=0时仍要执行一次，所以执行前的边界值为V₀(b)=S(b)，而非0。给定当前能力和概率表，完整历史对未来的影响可由b概括；加入h后，不再需要额外知道已经过了多少步。充分性条件和证明见[理论T1–T2](theory.md)。

**价值函数如何产生策略。** 以Q表示“现在先选某动作，之后采用最优策略”的价值，令μ_{−1}=q₀表示fallback：

```math
Q_h^*(b,\operatorname{Stop}(j))=R\mu_j(b),
```

```math
Q_h^*(b,\operatorname{Test}(i))=-\kappa+\sum_oP(o\mid b,i)V_{h-1}(\tau(b,i,o)),\qquad h>0.
```

对允许动作取最大得到V_h，对应的argmax给出π_h*。Q在代码中是各候选动作的临时计算值，不是训练得到的Q网络，也没有独立保存一张通用Q表。终止动作中的最大值可先合并为S(b)，便得到§2.2的Bellman式。

**实现采用什么求解过程。** 精确DP按有限时域的逆向归纳关系求解；代码以递归加缓存按需计算从当前根信念可达的计数状态，返回价值与策略。它不需要在无限时域上反复扫全状态空间直到价值函数收敛。Myopic用一步前瞻作局部选择，但后续仍可继续测试；深度前瞻、blinkered和上下界搜索是不同的规划近似。迭代加深增加前瞻深度，并不是经典策略迭代。

**固定策略评价与策略迭代的区别。** 对已保存策略，V_h^π(b)只评价它指定的动作：Stop(j)返回Rμ_j(b)；Test(i)则减去κ，并按结果概率评价保存的两个后续分支。这里没有对动作取max，因此可以将同一策略放到真实评价模型下复算，不能借真实后验替它重新选路。`evaluation.py`实现的是这种评价；代码没有运行经典“固定策略评价→贪心策略改进→再次评价”的策略迭代循环。搜索虽可逐步改善下界策略，其过程也不是经典策略迭代。

**序贯决策为何有意义。** 一次测试的即时奖励为负，但它可能使后续决策更好。连续测试反例中，一次成功仍不足以超过fallback，第二次成功才使终止选择改变；DP把第二步的可能收益传播回第一步，因而可以选择myopic不愿启动的测试。这里的信息获取类似探索，但目标是本回合的一次最终选择，不是标准bandit中每次拉臂都积累任务成功奖励。

**哪些东西在更新。** 贝叶斯更新是在推断未知路线类型；策略规划是在给定信念和模型后优化未来动作。能力变化由实验给定的p_C(s₀)→p_C(s₁)表示，测试本身不训练能力。校准实验用独立样本估计概率表，再固定该plug-in表规划；它没有在规划期间联合学习概率参数，也不是Bayes-adaptive求解。模型内最优与真实环境中的高效用须分开检查。

**预算对应哪一层。** B限制真实测试次数，是决策状态的一部分；M限制规划器计算后继信念的次数，是求策略的计算约束，不是本模型的环境动作。搜索的L由完整策略实现，U约束模型内最优值；L提高意味着策略价值改善，U降低意味着最优性不确定性缩小。两者分别对应正文§6的策略收益与认证收益。

因此，准确的课程定位是：**部分可观测环境中的信念状态建模、贝叶斯推断、有限时域Bellman最优控制，以及受计算预算约束的模型规划与评价**。项目没有实现Q-learning、策略梯度或经典策略迭代，不把校准估计和后验更新称为策略训练。

## 3. 实验设计与证据标准

固定R=1、q₀=0.5，三种先验(0.2,0.6,0.2)、(0.6,0.3,0.1)、(0.1,0.2,0.7)按路径独立等概率采样。主网格为K∈{3,6,10}、B∈{1,2,3}、n∈{0,3}、p_C(s₁)∈{0.1,0.5,0.9}、κ∈{0.005,0.02,0.1}，旧p_C=0.1、p_A=0.9；162设置各20任务，共3240。correct/reset/misread以精确DP比较。规划比较固定correct；搜索M=10000、ε=0.01，迭代加深同M。理论等价方法复用质量结果，不计为独立胜利。

大规模K∈{20,40}、B∈{4,6}、n∈{0,3}，当前p_C=0.5、κ=0.02，每设置20任务，共160；n=0/3共享先验抽样。预算100/1000/10000，ε=0.01/0.05。压力组复用主网格40任务，测试假定p_C=0.4/0.6，以及恰好一路径按原先验重采样。后者采用10个条件因子模型的均匀混合，不求一般相关POMDP最优解。

正式种子20261123，开发20261108，bootstrap20261129。正式数据的配置、种子和源码摘要见[data目录](../data/README.md)。方法/预算/压力变体不是独立样本：独立生成单位是任务，压力任务属于原主任务子集。

每个固定任务的效用精确积分未来结果，不附执行蒙特卡洛区间；跨任务平均差采用设置等权、设置内任务配对的5000次bootstrap，给出逐比较95%区间。机制分层为探索性，不作为多重比较校正后的确认性发现。没有预先定义实用等效阈值，故只报告绝对效应；1e-10用于数值零识别。全零样本不等于总体等效，只有对应理论恒等关系才支持一般性等价。

定向技术复核独立评价18设置的51条策略，最大误差3.33e-16；六种规划方法的更新调用数与记录一致。核心测试覆盖解析例子、独立枚举、预算、证书和策略评价。原基准通用runner的耗时包含公共上下文初始化，不能直接据此作跨记忆的纯算法速度排名。后续第5.3节及第6.4–6.6节的匹配计时排除公共输入构造和真实评价，纳入规划自身初始化与完整策略构造，以相同边界的wall/CPU耗时评价实际成本；后继更新及动作处理计数用于解释工作量。单worker不证明机器独占，速度结论仍限定本机与相应任务组。

## 4. Results：历史收益的条件与机制

有历史n=3的1620任务中，correct−reset平均差为0.081429（95% CI [0.074886,0.088053]），correct−misread为0.006387（[0.004643,0.008231]）。前者81.42%任务有正收益，后者7.22%。两种比较不可混为“记忆增益”。

我们逐任务作恒等分解：ΔJ=RΔP(终止成功)+κ[E N_other−E N_correct]。图1（[history_decomposition](../results/history/history_decomposition.pdf)）展示终止奖励与测试成本两项。当前p_C=0.5、κ=0.1时，correct和reset都全部立即停止；平均差0.131968完全来自终止路径选择，而非节省测试。

相对misread，行为错误还会反向变化。在p_C=0.5、κ=0.005切片，correct根节点停止率99.44%，misread为65%；净增益0.002477中0.002061来自避免无益重测。p_C=0.9时misread总是立即停止，而correct仍在5.6%–7.8%任务继续测试；测试成本项为负，但更好的终止选择补偿成本。误读既可能诱发无益测试，也可能过早放弃。

能力不变时correct与misread、无历史时三条件具有结构等价性。p_C=p_A=0.9时，历史成功已经排除I；C/A信念差异可能不改变当前执行率。因此行动变化不必转化为效用变化。先验组成与是否存在全成功历史的补充分层进一步刻画关联，但受K等因素混杂，不解释为独立因果效应。

一个精确的失败案例说明能力条件的重要性：先验(0.2,0.6,0.2)，旧表(0,0.1,0.9)，三次失败，当前表(0,0.9,0.9)，B=1、κ=0.02。correct预测率4923/7970≈0.617691，misread为9/2510≈0.003586。correct选择测试，成功后执行候选、失败后执行fallback，真实净值14487/19925≈0.727077；misread选择fallback，价值0.5。这里是固定构造的精确结果，不是总体平均效应。

## 5. Results：连续测试存在价值，为何平均收益仍小

解析例子设P(C)=1/20、P(A)=19/20，成功率4/5和1/20，fallback=1/2。初始成功概率7/80；一次成功后的预测11/28仍低于fallback；两次成功后为823/1100，高于fallback。首测失败后，再成功也不能越过fallback。因此两步最优策略是首测失败停止、成功才再测、仅SS执行候选。

该策略终止奖励改善273/32000，期望测试数87/80，故

```math
V_2(c)=\tfrac12+\max(0,\tfrac{273}{32000}-\tfrac{87}{80}c),\quad V_1(c)=\tfrac12.
```

固定q₀=0.5、令r=P(C)，一次成功仍不优于fallback而两次成功优于fallback的先验区间为3/515<r≤3/35；固定r=0.05时，对应fallback区间为11/28≤q₀<823/1100。这些边界由预测概率比较直接得到，限定在该两类型例子。

成本阈值c*=91/11600≈0.00784483；c=0.005时净改善0.00309375。11个预定成本点均与DP、固定策略评价一致。图2（[analytic_cost_boundary](../results/sequential/analytic_cost_boundary.pdf)）展示单一因素的机制边界；这是解析存在性和精确诊断，不替代随机基准。

在完整主网格，DP−滚动myopic平均差0.00018016，分解为正收益频率161/3240=4.9691%乘以条件收益0.00362550。B=2为9/1080，均值0.00002276；B=3为152/1080，均值0.00051771（95% CI [0.00046313,0.00057478]），条件收益0.00367844。图3（[gain_decomposition](../results/sequential/gain_decomposition.pdf)）并列总体、频率与条件幅度，防止只展示获益案例。

1980个任务双方根节点停止。161个获益任务中，仅9个是myopic停止而DP测试；34个首测路径不同，118个首测相同而后续不同。因此解析反例揭示存在性，却不是经验增益的唯一或主要形态。更深规划也可能通过减少不值得的后续测试获益：在固定κ=0.02切片，DP与myopic的平均测试数分别为0.656351与0.660503，净效用差0.00007272。B=2的成本节省汇总跨越不同κ，不能直接把成本下降解释为平均测试数下降。不能把“多步规划”解释为“总是多测”。

成本0.005/0.02/0.1对应获益任务121/38/2个；无历史组143个，有历史组18个。已有信息和成本共同压缩值得继续测试的区域。这些是固定网格描述；不据此宣称所有RL任务只需短视决策。

### 5.1 何时重测：闭式边界与历史链

单路径I/C、B1、0<q₀<p≤1时，令μ=pP(C|H)。一次信息毛价值G先随μ线性上升，再线性下降，μ≥q₀/(1−p+q₀)后为0。若0<κ<Rq₀(p−q₀)，严格重测区间为

```math
\frac{\kappa}{R(p-q_0)}<\mu<\frac{q_0-\kappa/R}{1-p+q_0}.
```

[完整推导与边界](theory.md)给出成功/失败后验、临界成本和平局规则。r=0.9、旧p=0.5、新p=0.8、q₀=0.5、κ=0.02时，n=0失败对应μ=0.72：失败后仍选候选，测试没有信息收益；n=1对应μ=0.654545：失败分支转选fallback，净重测优势0.021818，最优值0.676364；n=7对应μ=0.052555：成功分支过少，净重测优势−0.004234，选择fallback。该条件链不代表事前历史信息负价值。

### 5.2 区分需要测试与需要更深决策

全部3240任务的H=V*−S平均0.03502127，D=V*−J(myopic)平均0.00018016。分类结果为：1980任务H=0；1099任务H>0但D在1e-10内为0；161任务D>0。它们分别占61.11%、33.92%、4.97%。因此平均多步收益小不能只归因于“不用测试”：在1260个值得测试的任务中，1099个（87.22%）也已经由myopic取得精确值。161个正差任务条件均值0.00362550；D>0.001有119个，0.001只是奖励单位的辅助量级，不是统一实用标准。见[完整分类](../results/research/difficulty_classes.csv)和[区间](../results/research/difficulty_effects.csv)。

## 6. Results：策略质量、计算成本与证书

### 6.1 浅层充分性与正容差取舍

在主网格B=3的1080任务，myopic达到精确值的比例为85.93%，depth-2为97.59%，blinkered为91.57%，ε=0.01搜索为88.33%；M=10000迭代加深全部达到精确值。depth-3覆盖全部时域，与精确DP等价。图4（[shallow_sufficiency](../results/search/shallow_sufficiency.pdf)）同时展示精确值比例与实际regret，零识别容差不代表实用等效阈值。

对主实验所有199个未达精确值的搜索结果，保存状态全部为容差停止。诊断固定全部199个任务，保持M不变、只将ε改为0；199个全部达到精确值，平均更新数由27.96增至253.88，证书宽度归零。这是已有样本上的探索性干预，说明这些已观察损失来自主动容差取舍，不是预算不够；不将它计为新的独立确认样本。

### 6.2 相同M的优势与自然成本下的劣势

大规模n=0的80任务中，ε=0.01搜索相对迭代加深在M=100/1000/10000的平均差分别为0.001514、0.010897、0.001341，对应95%区间见[预算配对表](../results/study/tables/budget_pairs.csv)。M相同只表示后继信念预算相同。

迭代加深在M=100和1000返回相同策略。原因可从计数直接解释：在当前无历史概率表下，根及第一层之后两种观测概率都正，完整深度1需要2K次更新；深度2累计需要2K+(2K)^2次。K=20时是40/1640，K=40时是80/6480。因此1000不足以交付第二层，而10000可完成第二层。两个预定最大时域任务的实际计数、策略与此推导一致。搜索可以在部分树上逐步改善可执行策略，因而在层完成门槛之间具有优势。

自然成本下的结论不同。n=0中myopic和blinkered平均效用均为0.817001，分别平均使用540和3540次更新；M=10000搜索为0.812329，使用10000次更新，平均低0.004673（95% CI [−0.004999,−0.004349]）。它们没有相同预算，且myopic以便宜的一步判断构造了完整剩余时域策略，不受迭代加深“两层后立即停止”的执行限制。图5（[quality_cost](../results/search/quality_cost.pdf)）同时展示更新成本和观测耗时，不人为拖慢便宜基线。M=10000时搜索记录约130万次计数的动作处理（未跳过的回传与前沿候选处理，不含全部遍历和剪枝标记比较），迭代加深约5101次动作评估；这反映额外管理工作，但不是统一FLOP计量或独立的耗时因果分解。

### 6.3 证书提供什么、没有提供什么

n=3的80任务全部满足初始停止判据，搜索无需更新即可给出零宽度证书。该现象说明信息价值已低，不作为搜索普遍速度优势；其他方法也可使用同一数学判据。解析下界预言这种任务很常见，但样本80/80不代表所有可能任务都停止。

n=0时，搜索初始上界均值0.879893；M从100增至10000，下界从0.795614升至0.812329，上界从0.859893降至0.841813，证书宽度从0.064278降至0.029484。最后仍未满足0.01，说明在该预算下证明质量比找到可行高值策略更困难。图6（[certificate_decomposition](../results/search/certificate_decomposition.pdf)）同时展示初始上界、最终上界、搜索策略值和myopic可行值。

同一模型的U也约束myopic，因此最终U−J(myopic)均值0.024811可作为基线的事后质量上界。但这个U来自额外搜索，必须承担搜索成本；它不是myopic免费得到的证书，也不等于真实regret。主网格有精确参照，B=3中308个搜索策略已达到精确值却仍有正界宽，直接说明界宽与实际损失不是同一量。

### 6.4 独立确认：myopic初始化究竟改善了什么

根节点初始化变体先保留完整myopic策略，再继续原搜索。初始化和后续搜索共用限额缓存；M<1000固定使用原搜索，初始化无法完成时保留STOP并记录全部成本。完整初始化时返回值不低于myopic是结构性质，不作为经验创新。

独立种子20261124生成相同large配置的160任务，n=0/3共享先验，未与旧任务混合排名。预定主比较为80个无历史任务中M10000、ε0的warm−cold证书宽度。平均差为−0.00450202，设置内配对5000次bootstrap的95%区间为[−0.00483372,−0.00418280]。

| 同批次方法 | 平均效用 | 平均更新次数 | 平均证书宽度 |
|---|---:|---:|---:|
| myopic | 0.81737112 | 540 | 无搜索证书 |
| blinkered | 0.81737112 | 3540 | 无搜索证书 |
| 原搜索，M10000 | 0.81286910 | 10000 | 0.02895140 |
| 初始化搜索，M10000 | 0.81737112 | 10000 | 0.02444938 |

80个无历史任务的初始化均完成，但后续搜索没有任何任务提高myopic的效用；最终上界与原搜索逐任务在1e-10内一致。因此主比较的宽度改善全部来自更高的下界，没有观察到相对原搜索额外的上界收紧。初始化后到搜索结束，上界平均下降0.03814，下界不变：额外计算获得了认证信息，未获得更好的执行策略。零样本差异不证明任意任务上的总体等效，也不证明myopic已是大规模精确最优。

M1000时初始化平均占540次更新，最终上界反而比原搜索高约0.0047325，体现了初始化的机会成本；其更强下界仍使最终宽度较小。M100的变体按预定规则等于原搜索，没有用它证明初始化有效。无历史组两种搜索在全部预算下均未达到ε=0.01；有历史80任务均解析停止，不做初始化。

计时从每设置预定index0–3取32任务，四方法各重复三次、固定随机顺序、冷缓存、单工作进程及数值线程。公共输入在计时外构造，方法内部全部初始化和策略构造在计时内，另记process CPU。无历史16任务先在任务内取重复中位数，再跨任务取中位数：原搜索约0.5438秒，初始化搜索0.5147秒，myopic 0.00467秒，blinkered 0.01969秒；CPU中位数分别约0.5435/0.5144/0.00466/0.01969秒。这是同任务的本机观测成本，不是独占机器或总体速度优势检验。初始化搜索相对myopic约两个数量级的时间并未换来更高效用。

[质量与成本图](../results/planning/planning_comparison.pdf)和[初始化分解图](../results/planning/initialization_decomposition.pdf)分别给出同批次比较和检查点分解；全部结束状态、计时及配对数据见[确认结果](../results/planning/README.md)。本次结论支持在需要模型内质量上界时保留初始化搜索；若只要求当前分布上的策略效用，新增实验没有提供支付额外搜索成本的收益依据。不继续增加变体或样本。

### 6.5 初始化、证书和额外成本的分账

复核上述独立批次的未舍入策略：80/80个无历史任务的最终策略树与myopic完全相同；并非仅真实价值相同。初始化后L₀=0.81737112、U₀=0.87996，结束时L_T不变、U_T=0.84182050。故Δ_policy=0，Δ_upper=Δ_width=0.03814，后两者95%设置内配对区间[0.03784,0.03844]；最终宽度0.02444938，0/80满足0.01。初始化平均540次更新，后续9460次；相对cold的更强下界0.00450202是已知策略带来的，不是搜索新收益。

缺少的阶段计时只在8个预定任务各重复三次补测，策略与计算次数均与冻结记录一致。无历史4任务的阶段中位数：根上界与初始化管理前准备约0.0000256秒、完整myopic构造0.004586秒、后续搜索0.490985秒；完整规划中位数0.503119秒。各阶段中位数不相加；[原始分账及均值](../results/research/phase_timing.csv)保留全部阶段，总时间逐条等于其组成之和。输入构造和真实评价在规划外，后者中位数约0.0000220秒。计时只描述此固定子集；前节32任务的匹配比较保持原值。

这些任务中，若只求可执行策略效用，额外搜索没有实测收益；若需要模型内最优性不确定性上界，额外搜索提供0.03814的收紧，但不能承诺0.01。是否值得该时间还取决于应用对证书的要求，本模型没有给CPU时间定价。本条算法扩展已关闭。

### 6.6 显式剪枝的管理成本消融

为兑现原Proposal关于剪枝速度影响的承诺，复用原large中K=40、B=6、n=0的全部20任务，保持correct、STOP下界初始化、M=10000和ε=0.01，只切换`prune=True/False`。关闭显式标记后，最大上界优先规则仍避免继续探索被支配动作；本对照不是取消全部分支定界。40条完整策略经固定策略评价复算，开启剪枝的20条结果与原冻结记录一致。两方法逐任务策略、效用、上下界、后继更新数和展开数全部相同；均耗尽10000更新预算，均无任务达到0.01容差。

## 7. 压力测试与适用边界

假定当前p_C=0.4时，20个无历史任务的精确误设策略全部与nominal策略相同，虽然模型价值平均绝对误差约0.00554；真实regret为零。假定0.6时，18/20个策略改变，平均真实regret约0.000598。两个有历史条件中20/20策略均保持相同。行动稳定性解释了为何模型值偏差不总产生决策损失；有限样本中的零不证明任意误设无害。

恰有一路径重采样后，有历史组nominal DP相对reset平均真实效用仍高0.080298（95% CI [0.040662,0.123482]）。没有求该相关环境的真实最优策略，所以这只是策略间比较，不是regret或最优性结论。无历史时重采样保持原先验乘积分布，是严格负对照。

### 7.1 有限校准样本：从概率误差到决策损失

固定36个原main任务（K3/B3，n0/3，三个能力值、三个成本，index0/1），使用独立合成已知类型校准。m=10/30/100/300各30重复；每个C参数m个观测，能力无关A合并两批共2m个观测，I保持0；Beta(1,1)后验均值作为冻结plug-in表。一次重复的参数表在36任务间共享，bootstrap以独立校准重复为聚类，不能将任务×重复当独立样本。真实类型未进入规划器，真值评价对同一实际历史和完整策略精确积分。

| 每个C参数样本m | 参数MAE（五参数等权） | 估计DP真实regret（95%聚类区间） | 估计myopic真实regret |
|---|---:|---|---:|
| 10 | 0.082232 | 0.00206808 [0.00165155,0.00250758] | 0.00333766 |
| 30 | 0.045448 | 0.00153279 [0.00115781,0.00197958] | 0.00226976 |
| 100 | 0.027856 | 0.00075103 [0.00058686,0.00092534] | 0.00129934 |
| 300 | 0.013605 | 0.00028920 [0.00019753,0.00039190] | 0.00087497 |

预定主终点m300−m10的估计DP平均真实regret差为−0.00177888，95%区间[−0.00221848,−0.00135398]。每个样本量先在同一固定36任务上平均真实损失，再按预先规定的repeat编号将m300与m10的30个聚类均值配对作差，对30个差值进行5000次percentile bootstrap。两种样本量的校准数据独立，不是共享校准样本或嵌套扩样；同一估计表内的任务不作为独立校准样本。支持固定任务集上端点平均改善，不保证逐任务/逐重复单调，也不覆盖任务总体抽样不确定性。详见[配对比较](../results/research/calibration_comparisons.csv)与[统计图](../results/research/calibration.png)。

m10时71.85%的估计DP策略与真实表DP完全相同，另3.15%策略不同但真实价值相同；只有25%产生超过1e-10的真实损失。m300相应为90.19%、2.22%和7.59%。参数误差经常不改变策略，因此不改变该策略的真实效用。当误差改变了真实模型下有正概率到达的决策，并使其偏离真实最优选择时，才可能产生效用损失。动作变化可能只是平局处换了路径；一般也可能仅发生在不可达分支，所以策略树不同不等于真实损失。本组同价值异策略案例按真实固定策略评价识别，不把结构变化次数当作损失次数。m10的绝对模型价值误差均值0.049892，远大于真实regret 0.002068，说明预测偏差与决策损失必须分别报告。

一个按固定顺序取出的后续分歧案例（m10重复0，n0、当前C=0.1、成本0.005、index1）中，C估为0.083333、A估为0.863636。首次路径0成功后，真实模型仍认为继续测试比停止高0.00046923；估计模型反而认为停止比真实DP后续策略高0.00297356，故提前停止。根真实损失为0.000305。另一个根动作改变案例在真实C=A=0.9时发生：估计表将二者分别估为0.916667/0.863636，打破原本类型成功率相同的结构，改变测试配置并产生0.002313损失。[案例文件](../results/research/calibration_examples.json)保存双方策略、真实与估计后验、局部偏好和完整参数，案例选择不用于估计频率。

有历史n3的平均路径后验TV由m10的0.056689降至m300的0.008425，真实regret由0.001530降至0.000262。预定两任务小切片（n3、C=0.5、成本0.02）分别只扰动历史、只扰动未来及同时扰动，全部保持零regret；这说明该局部决策稳定，不能据此分解其他任务的损失来源。没有为得到非零分解而扩展切片。

估计DP在估计模型内已精确，真实regret仍为正；模型内零证书不是现实保证。T3初始信念TV界不能覆盖同时变化的未来观测机制。校准可观察类型是隔离误差来源的实验假设，不是提出了现实场景中的标签获取方案。

## 8. Discussion：能从结果推出什么

历史价值不只体现为少测试；它也体现为停止时选得更好，或知道何时值得支付新测试成本。正确记忆相对reset和misread的收益发生频率和方向机制不同，这使“保存更多历史”与“正确解释历史”成为两个可区分问题。

连续测试的价值由跨越终止选择边界决定。解析例子中的一次成功尚不足以越过fallback，两次成功才可能改变选择；主网格中大量myopic策略已达到精确值，平均收益被大量零增益任务稀释，非零条件收益也有限。我们同时保留存在性证明和分布量级，不用其中一个取代另一个。

搜索的收益来自渐进构造策略，成本来自价值界、扫描与扩展。M相同的优势可以与自然成本劣势并存；初始STOP下界和PI上界尚有较大距离时，找到高值策略与缩小证明区间需要不同计算。独立确认中的myopic初始化提高了下界，但未观察到超出myopic的效用增益；后续计算主要用于缩小模型内上界。24个预定小机制任务中两种搜索均取得精确值，说明其用途依赖改善空间与计算规模，不能由large结论推成所有任务均不值得搜索。

显式剪枝消融进一步检验了“少做一些动作处理是否真的更快”：相同策略、界与展开次数下，动作处理计数减少约0.176%，而本机匹配耗时约增加0.96%。计数没有覆盖标记与遍历等开销，故不能直接代表总成本；本实验也没有分别识别这些开销的贡献。安全剪枝的数学性质、计数上的工作节省和实际耗时收益需要分别验证，局部减速不意味着一般剪枝方法无效。

我们的统计范围是固定网格及指定任务生成分布；先验/历史子群关联未隔离全部混杂。压力测试覆盖有限偏移，不证明一般鲁棒性。大规模真实最优值未知，耗时非隔离微基准。主模型使用已知概率表、固定类型和条件独立；新增校准组检验有限样本plug-in概率表，仍不处理真实标签获得、在线参数学习或一般环境漂移。

## 9. Conclusion

研究冻结后的四条结论分别是：

- **历史解释**：历史似然应使用观测发生时的能力，而非直接套用当前成功概率；理论见[T1](theory.md)，原基准的收益及机制见[历史结果](../results/history/overall.csv)。这不要求所有历史都改变行动。
- **是否重测**：信息改变后续及最终选择的潜在收益必须超过测试成本；单路径一次重测的中间信念区间由[T6](theory.md)和[解析案例](../results/research/threshold_cases.json)确定。第一步不改变终止选择，也可能开启有价值的连续测试。
- **规划方法**：原主网格、大规模独立确认与确定性机制任务分别揭示浅层充分性、认证成本和跨路径规划收益。24任务的[强基线完整比较](../results/research/deep_summary.csv)显示blinkered接近最优、DP便宜、搜索正确但汇总耗时更高；不据机制任务宣称搜索普遍占优，也不由大规模负面结果否定多步规划。[显式剪枝消融](../results/pruning/summary.csv)在该实现及20个既有任务上保持策略质量，却未获得耗时收益，说明方法选择还须核算管理成本。
- **概率估计**：在固定36任务上，更多校准样本降低平均真实损失，完整区间见[预定比较](../results/research/calibration_comparisons.csv)。误差是否造成损失取决于可达决策及真实价值间隔，[策略案例](../results/research/calibration_examples.json)区分参数偏差、策略变化与真实损失；零损失归因切片没有识别出总体损失来源。

原基准总体、独立确认、确定性机制诊断、有限校准及既有样本剪枝消融保持各自分母与统计单位，不合并均值；120条剪枝计时不增加独立任务数。现有成果已覆盖本轮研究范围；保留大任务精确最优值未知、校准小切片不能分摊总体误差来源等适用边界，不再扩展算法或实验。
